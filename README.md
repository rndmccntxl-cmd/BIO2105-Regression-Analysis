# BIO2105: Chapter 9 — Regression Analysis

This repository contains the R Markdown report, R script, and knitted output for **Formative Assessment 12** in **BIO2105 - Biostatistics**, covering correlation, linear transformation invariance, simple linear regression, sum-of-squares decomposition, and residual diagnostics on built-in R datasets.

## Datasets Used

- **`trees` (Part I):** Measurements of trunk girth (`Girth`, in inches), height (`Height`, in feet), and timber volume (`Volume`, in cubic feet) for $n = 31$ felled black cherry trees.
- **`women` (Part II):** Average height (`height`, in inches) and average weight (`weight`, in pounds) for $n = 15$ American women aged 30–39.
